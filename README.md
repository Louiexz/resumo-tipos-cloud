# resumo-tipos-cloud
Repositório do lab "Configurando uma instância de Banco de Dados na Azure" da Digital Innovation One.

## Tipos de Cloud
- SaaS (Software como Serviço) – Voltado para o público geral, oferece acesso rápido e está pronto para uso imediato.
- PaaS (Plataforma como Serviço) – Permite maior controle sobre o gerenciamento, sendo principalmente utilizado por desenvolvedores.
- IaaS (Infraestrutura como Serviço) – Oferece controle quase total, permitindo maior liberdade na criação e personalização de sistemas.

## Conclusão
A escolha do tipo de serviço depende do seu nível de conhecimento, das necessidades específicas do projeto e do custo desejado. Quanto maior a dependência de gerenciamento por parte do provedor, maior pode ser o custo. Portanto, é importante encontrar um equilíbrio entre as diferentes tecnologias para aproveitar ao máximo os recursos disponíveis.
